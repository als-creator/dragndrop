# Drag-and-Drop Интеракция

Простой JavaScript‑скрипт для реализации функционала перетаскивания элемента (`drag-and-drop`) между областями‑заполнителями.

## Функционал

* **Перетаскивание элемента:** пользователь может захватить элемент с классом `.item` и переместить его.
* **Визуальная обратная связь:**
  * при начале перетаскивания элемент получает класс `hold`, затем `hide` (становится полупрозрачным);
  * заполнители получают класс `hovered` при наведении над ними перетаскиваемого элемента.
* **Размещение элемента:** при отпускании (`drop`) элемент помещается внутрь заполнителя.
* **Сброс состояний:** после завершения перетаскивания стили сбрасываются.
